# AI-ML-DL-books
A curated collection of AI, Machine Learning, Deep Learning, and Statistics books in PDF/EPUB format.

## Machine Learning
- [The Hundred-Page Machine Learning Book](https://themlbook.com/)  
  Author: Andriy Burkov  
  Latest Edition: 1st Edition  
  Focus: Compact overview of key machine learning concepts and practical approaches without heavy mathematical depth.  
  Files: [PDF](./Machine_learning/The%20Hundred-page%20Machine%20Learning.pdf)
- [Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (3rd Edition)](https://www.oreilly.com/library/view/hands-on-machine-learning/9781098125967/)  
  Author: Aurélien Géron  
  Latest Edition: 3rd Edition  
  Focus: Practical end-to-end machine learning workflows using Python, scikit-learn, Keras, and TensorFlow.  
  Files: [PDF](./Machine_learning/Hands-On%20Machine%20Learning%20with%20Scikit-Learn%2C%20Keras%2C%20and%20TensorFlow%20%282022%29.pdf)

## Deep Learning
- [Deep Learning (Goodfellow, Bengio, Courville)](https://www.deeplearningbook.org/)  
  Author: Ian Goodfellow, Yoshua Bengio, Aaron Courville  
  Latest Edition: 1st Edition  
  Focus: Foundational deep learning text covering theory, architectures, optimization, and representation learning.  
  Files: [PDF](./Deep_learning/Deep%20Learning%20by%20Ian%20Goodfellow.pdf) | [EPUB](./Deep_learning/Deep%20Learning%20by%20Ian%20Goodfellow.epub)
- [Deep Learning with Python (Third Edition)](https://www.manning.com/books/deep-learning-with-python-third-edition)  
  Author: François Chollet, Matthew Watson  
  Latest Edition: 3rd Edition  
  Focus: Hands-on deep learning with Python and Keras, focused on modern workflows and practical model building.  
  Files: [PDF](./Deep_learning/Deep%20Learning%20with%20Python%2C%20Third%20Edition%20%28Francois%20Chollet%2C%20Matthew%20Watson%29.pdf) | [EPUB](./Deep_learning/Deep%20Learning%20with%20Python%2C%20Third%20Edition%20%28Francois%20Chollet%2C%20Matthew%20Watson%29.epub)
- [Deep Learning for Computer Vision](https://www.packtpub.com/en-in/product/deep-learning-for-computer-vision-9781788831109)  
  Author: Rajalingappaa Shanmugamani  
  Latest Edition: 1st Edition  
  Focus: Computer vision-focused deep learning for image classification, object detection, and face recognition in Python.  
  Files: [PDF](./Deep_learning/Deep%20Learning%20for%20Computer%20Vision%20-%20Image%20Classification%2C%20Object%20Detection%20and%20Face%20Recognition%20in%20Python.pdf)
